# Campus IA - Assistant Universitaire

Un bot Telegram intelligent conçu pour répondre aux questions des étudiants de l'Université Révérend Kim (L3 LMD RX).

## 🛠️ Technologies utilisées
- Python
- API Telegram
- Ubuntu Server

## 🚀 Installation
1. Cloner le dépôt
2. Créer un fichier `.env` avec le `TELEGRAM_TOKEN`
3. Installer les dépendances : `pip install -r requirements.txt`
4. Lancer le bot : `python3 bot.py`
